# Словарь для запоминания

Слова хранятся во фразах (контекст уровня B1), чтобы легче запоминались и
импортировались в приложения для интервального повторения (ReWord, Anki, Quizlet).

## Структура

```
vocab/
└── de-ru/                немецкий → русский
    ├── b1.csv            карточки: слово, перевод, фраза
    └── grammar-notes.md  короткие грамматические подсказки
```

Чтобы добавить другой уровень или язык — создай рядом новый файл/папку,
например `de-ru/a2.csv` или `en-ru/b1.csv`.

## Формат CSV

Три колонки, разделитель — запятая, все поля в двойных кавычках (внутри полей
могут быть запятые):

```
word,translation,phrase
"das Lied (-er)","песня","Dieses Lied gefällt mir besonders gut."
```

- **word** — немецкое слово; у существительных указан артикль и форма
  множественного числа в скобках, у глаголов с управлением — предлог и падеж.
- **translation** — перевод на русский.
- **phrase** — пример-фраза уровня B1, где слово стоит в контексте.

Первая строка — заголовок. Если приложение для импорта не умеет его пропускать,
удали её перед импортом.

## Импорт в ReWord и другие приложения

ReWord и большинство приложений импортируют пары «слово — перевод». Варианты:

- **Слово ↔ перевод** — импортируй только колонки `word` и `translation`.
- **Слово ↔ перевод + фраза** — объедини `translation` и `phrase` в одну
  колонку (оборот карточки), чтобы видеть пример вместе с переводом.

Quizlet/Anki принимают CSV/TSV напрямую: укажи разделитель «запятая» и, при
необходимости, поменяй порядок колонок под нужное направление карточек.
