# Словарь для запоминания

Слова хранятся во фразах (контекст уровня B1), чтобы легче запоминались и
импортировались в приложения для интервального повторения (ReWord, Anki, Quizlet).

## Структура

```
vocab/
└── de-ru/                немецкий → русский
    ├── b1.csv            карточки: слово, перевод, фраза, перевод фразы (источник)
    ├── grammar-notes.md  короткие грамматические подсказки
    └── exports/          готовые файлы под приложения
        ├── algoapp-import.csv   front,back,example (comma-CSV, UTF-8)
        ├── quizlet-import.txt   слово ⇥ перевод — фраза
        └── reword-import.csv    "слово";"перевод";"фраза";"перевод фразы" (UTF-8)
```

Источник правды — `b1.csv`. Файлы в `exports/` генерируются из него; если
правишь слова, обнови и экспорт.

Чтобы добавить другой уровень или язык — создай рядом новый файл/папку,
например `de-ru/a2.csv` или `en-ru/b1.csv`.

## Формат источника (b1.csv)

Четыре колонки, разделитель — запятая, все поля в двойных кавычках (внутри полей
могут быть запятые):

```
word,translation,phrase,phrase_ru
"das Lied (-er)","песня","Dieses Lied gefällt mir besonders gut.","Эта песня мне особенно нравится."
```

- **word** — немецкое слово; у существительных указан артикль и форма
  множественного числа в скобках, у глаголов с управлением — предлог и падеж.
- **translation** — перевод на русский.
- **phrase** — пример-фраза уровня B1, где слово стоит в контексте.
- **phrase_ru** — перевод фразы на русский.

Первая строка — заголовок. Если приложение для импорта не умеет его пропускать,
удали её перед импортом.

## Импорт по приложениям

- **ReWord** → `exports/reword-import.csv`. Формат ReWord: разделитель — точка с
  запятой, поля в кавычках, UTF-8, по 4 поля в строке:
  `"слово";"перевод";"фраза";"перевод фразы"`. В приложении: выбрать текстовый
  (txt/csv) файл при импорте.
- **Quizlet** → `exports/quizlet-import.txt`. Между термином и определением —
  «Табуляция», между карточками — «Новая строка».
- **AlgoApp** → `exports/algoapp-import.csv`. Обычный comma-CSV; на экране
  маппинга связать `front`/`back`/`example`.
